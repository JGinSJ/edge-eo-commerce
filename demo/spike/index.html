Content negotiation at the edge · thought-leadership spike

Prioritized delivery — who's asking decides which HTML they get

One URL. The edge inspects who's asking and routes each visitor to the right payload: a person and search crawlers get the full page; AI crawlers get skinny HTML (chrome stripped); answer engines get prioritized HTML (chrome stripped and the answer hoisted first). Each variant is derived from a per-template config — 50 configs → 375k pages — and the routing mirrors the edge's crawler-policy.
